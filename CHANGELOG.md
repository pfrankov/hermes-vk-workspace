# Changelog

## 0.1.1 — 2026-10-20

### Исправлено

- Проверка доверенных origin использует тот же URL-парсер, что и HTTP-клиент. Международные домены больше не могут пройти проверку под другим ASCII-именем; эквивалентные записи IPv6 распознаются одинаково.

### Изменено

- Цикломатическая сложность ограничена 10 на функцию правилом Ruff C901 в CI. Упрощены разбор событий, объединение правок, обработка вложений, валидация кнопок и HTML-форматирование.
- Убраны неиспользуемые поле настроек и аргумент метода. Вложения дедуплицируются одной структурой, переходы HTML-тегов вычисляются один раз на текстовый сегмент. Преобразование аудио размещено вместе с остальной обработкой медиа.
- Тесты адаптера и меню используют общую фикстуру настоящего адаптера и API mock с проверкой сигнатур. Удалён отдельный тестовый адаптер с дублирующими методами; ожидаемое содержимое форматированных сообщений задано независимо от реализации.
- Добавлены регрессии для IDNA и IPv6, схемы кнопок и точных границ HTML, экранирования и UTF-16. Повторно сверены все 11 методов Bot API с официальными SDK.
- `yarl`, уже устанавливаемый с `aiohttp`, объявлен прямой закреплённой зависимостью. Добавлены правила упрощения кода, порядок подачи в каталог Hermes и описание доступа к данным.

## 0.1.0 — 2026-10-20

Первый выпуск платформы VK Workspace / VK Teams для Hermes Agent v0.22.2.

### Добавлено

- Нативная регистрация платформы и установка через plugin manager Hermes.
- Long polling с атомарным cursor, ограниченным dedup-кешем, backoff и блокировкой единственного потребителя токена.
- Личные чаты, группы, каналы и нативные дочерние чаты обсуждений.
- Авторизация Hermes до загрузки медиа, настройка разрешённых чатов и проверка прямых упоминаний.
- Сохранение цитат и пересылок как контекста без исполнения вложенных команд.
- Потоковые ответы, безопасное форматирование Markdown, длинные сообщения и подписи.
- Приём и отправка файлов, изображений, видео и аудио; голосовые сообщения с распознаванием контейнера и конвертацией TTS через ffmpeg.
- Ограничения origin, переадресаций, HTTP-ответов и размеров файлов; безопасные диагностические сообщения.
- Отказ от скрытого повтора мутаций API и автоматического продолжения при неопределённой доставке.
- Одноразовые меню выбора провайдера, модели и стандартных параметров Hermes с проверкой пользователя, чата, сообщения и сессии.
- Изолированная отправка для cron и `hermes send`, поддержка профилей Hermes.
- Тесты HTTP-контракта и границ безопасности, проверки на настоящем Hermes, CI и правила code review.

### Границы первой версии

- Поддерживается актуальный контракт Hermes; совместимость со старыми версиями не реализуется.
- Cursor подтверждает приём gateway. Отдельной долговечной очереди и гарантии exactly-once нет.
- Подтверждения инструментов и уточняющие вопросы используют штатный текстовый протокол Hermes.
- Проверки не требуют рабочего токена и не считаются испытанием на живом сервере VK Teams.
